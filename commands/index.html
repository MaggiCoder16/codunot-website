/models

View currently available AI model options.

/model model:<choice>

Switch active model per channel/DM and refresh short-term memory context.

Model choices: Llama 4 Scout 17B (default/vision), GPT-OSS-120B, CoduChat V1 (groq/compound-mini), CoduChat V2 (groq/compound), Allam 2 7B, Qwen3 32B, Llama 3.3 70B, and Llama 3.1 8B.

2) General Chat, Utility & Roleplay

Core usage: mention @Codunot AI in server chat, use DMs directly, reply to a message to include additional context, or upload .txt, .pdf, and .docx files for AI reading.

Utility commands: /helpc, /shard, /browse url:<required>, /test_code, /image_search query:<required>, and /customise_bot_profile (Gold/Enterprise).

Action commands: /hug, /kiss, /kick, /slap, /wish_goodmorning, /bet side:<heads|tails>, and /meme.

3) AI Media & Vision (Vote Required)

Attachment quotas: Free 7/day, Premium 25/day, Gold/Enterprise unlimited.

  • /generate_image prompt:<required> — boosted prompt flow for cinematic 1:1 generation.
  • /edit_image image:<required> prompt:<required> — transform uploaded images with text instructions.
  • /analyse_image image:<required> prompt:<optional> — image Q&A using the default vision-compatible model.
  • /merge_image image1 image2 image3? image4? prompt? — blend 2-4 images into one output.
  • /generate_video prompt:<required> — AI video generation pipeline.
  • /transcribe video_url:<required> — text transcript from supported video sources (up to 30 minutes).
  • /generate_tts text language voice — MP3 TTS generation across 70+ languages.

4) Advanced Music System

Audio playback runs on redundant Lavalink infrastructure with tier-based quality from 64 kbps to 160 kbps.

Playback controls: /play, /stop, /skip, /queue, /history, /nowplaying, /volume, /remove, /shuffle, /loop, /autoplay, /lyrics, /bitrate.

Filters: /bassboost, /nightcore, /slow, /eightd, /treble, /lofi, /vaporwave, and /resetfilters.

Server playlists: /playlistcreate and /playlist for persistent queue workflows.

5) Moderation, AutoMod & Security

Natural moderation: plain-language moderation requests can be issued by mentioning Codunot (for example, timeout/ban/warn flows).

Core moderation commands: /warn, /warns, /clearwarns, /modkick, /ban, /unban, /mute, /unmute, /clear, /clear_all, /lock, /unlock, /slowmode, /userinfo, and /case.

Advanced moderation: /tempban, /massban, /modstats, /note add|view|clear, /shadowban add|remove|list, /sticky set|clear|list, and /adaptive-slowmode.

Setup wizard: /setup-moderation guides bad words, mod logs, mod roles, link policy, anti-spam, anti-raid, and exemption setup.

6) Ticketing & Server Configuration

Bot chat scope: /configure server enables all channels, while /configure channels limits replies to selected channels.

Ticketing wizard: /ticketing-setup configures staff role access, panel channel, log channel, optional categories, and optional enterprise requirements prompts.

In-ticket actions: close ticket (all tiers), priority queue/show queue (Premium+), and claim ticket (Gold+).

8) Top.gg Voting Unlocks

When a locked command is used, the vote flow unlocks media features for 12 hours after a successful vote.

Unlocked set includes /generate_image, /edit_image, /merge_image, /analyse_image, /generate_video, /generate_tts, /transcribe, /play, and music filters.
