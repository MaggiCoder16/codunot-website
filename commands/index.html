AI Personas, Modes & Models

/funmode

Fun mode (default): playful, witty, and expressive responses.

/seriousmode

Professional and fact-focused responses for work and study.

/roastmode

Savage roast mode with high-energy banter.

/teachmerizz online

Online DM/texting social coach.

/teachmerizz irl

IRL social coaching (Premium, Gold, Enterprise).

/chessmode

Play live chess with Codunot (you are White, bot is Black).

/models

Lists currently available models.

/model model:<choice>

Switch active model per channel/DM and reset short context memory.

Model choices: Llama 4 Scout 17B (default, required for vision), GPT-OSS-120B, Kimi K2 Instruct, Allam 2 7B, Qwen3 32B, Llama 3.3 70B, Llama 3.1 8B.

General Chat, Tools & Roleplay

Natural chat via mention and DMs, reply-context reading, and file reading for .txt, .pdf, and .docx.

Core utility commands: /helpc, /shard, /browse url:<required>, /test_code, /image_search query:<required>, /customise_bot_profile (Gold and Enterprise).

Action commands: /hug, /kiss, /kick, /slap, /wish_goodmorning (requires target_user), /bet side:<heads|tails>, /meme.

AI Media & Vision (Vote Required)

Attachment quotas: Free 7/day, Premium 25/day, Gold/Enterprise unlimited.

  • /generate_image prompt:<required> — prompt boosted then rendered 1:1.
  • /edit_image image:<required> prompt:<required>.
  • /analyse_image image:<required> prompt:<optional> (default model required).
  • /merge_image image1 image2 (+ optional image3/image4/prompt). Hidden shortcut: upload 2+ images and type “merge”.
  • /generate_video prompt:<required> — cinematic video generation.
  • /transcribe video_url:<required> — max 30 mins.
  • /generate_tts text language voice — 70+ languages.

Advanced Music System

Powered by 5 load-balanced Lavalink nodes. Tier-based audio quality from 64 kbps to 160 kbps.

Playback: /play, /stop, /skip, /queue, /history, /nowplaying, /volume level:0-200, /remove index, /shuffle, /loop mode:track|queue|off, /autoplay, /lyrics, /bitrate.

Filters (vote required): /bassboost, /nightcore, /slow, /eightd, /treble, /lofi, /vaporwave, /resetfilters.

Playlists: /playlistcreate and /playlist.

Moderation, AutoMod & Security

Natural moderation is supported (example: @Codunot AI timeout @User 10m for spamming).

Free moderation: /warn, /warns, /clearwarns, /modkick, /ban, /unban, /mute, /unmute, /clear, /clear_all, /lock, /unlock, /slowmode, /userinfo, /case.

Premium+ moderation: /tempban, /massban, /modstats, /note add|view|clear, /shadowban add|remove|list, /sticky set|clear|list.

Gold+: /adaptive-slowmode (Enterprise includes advanced threshold controls).

Setup: /setup-moderation provides a 7-step wizard. /automod action:enable|disable is the quick toggle.

Ticketing System & Server Configuration

/configure server allows bot chat in all channels. /configure channels restricts bot chat to specific channels.

/ticketing-setup provides the full wizard for staff role, panel channel, logs, categories (Gold+), and requirements prompt (Enterprise).

In-ticket controls: Close Ticket (all tiers), Priority Queue + Show Queue (Premium+), Claim Ticket (Gold+).

Top.gg Voting System

When you use locked commands, Codunot shows a Vote button. One vote unlocks media features for 12 hours.

Unlocked command set includes: /generate_image, /edit_image, /merge_image, /analyse_image, /generate_video, /generate_tts, /transcribe, /play, and all music filters.
