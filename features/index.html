Chat Experience

  • Chat in DMs or by mentioning Codunot in your server.
  • Switch response style anytime with /funmode, /seriousmode, /roastmode, /teachmerizz, and /chessmode.
  • Choose a chat model per channel or DM using /model.
  • View available models using /models.
  • Send images during normal chat for image-aware responses.

Available chat models

  • openai/gpt-oss-120b
  • CoduChat V1
  • CoduChat V2
  • allam-2-7b
  • qwen/qwen3-32b
  • llama-3.3-70b-versatile
  • meta-llama/llama-4-scout-17b-16e-instruct (default)
  • llama-3.1-8b-instant

Moderation & Safety

Protect your server with moderation tools that scale from starter communities to large teams.

Core moderation (all tiers)

  • /setup-moderation, /automod, /warn, /warns, /clearwarns
  • /ban, /unban, /modkick, /mute, /unmute
  • /clear, /slowmode, /lock, /unlock
  • /userinfo, /case

Premium / Gold / Enterprise

  • /tempban, /massban, /modstats
  • /shadowban add, /shadowban remove, /shadowban list
  • /sticky set, /sticky clear, /sticky list
  • /note add, /note view, /note clear

Gold / Enterprise

  • /adaptive-slowmode for burst-aware slowmode behavior.

Enterprise extras

  • Custom moderation thresholds and slowmode timing.
  • Optional AI moderation toggle support.

Ticketing

Set up structured support channels with private ticket threads and staff workflows.

  • /ticketing-setup launches the guided setup for staff role, panel channel, and logging channel.
  • All tiers: open ticket button, private ticket channel, and close-ticket controls.
  • Premium, Gold, and Enterprise: priority queue and queue visibility buttons.
  • Gold and Enterprise: claim ticket button and custom ticket categories.
  • Enterprise: custom requirements prompt before opening a ticket.
