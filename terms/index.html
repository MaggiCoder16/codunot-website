5. Features and Access

Codunot provides a variety of AI-powered features that operate automatically or through explicit commands:

Automatic Features (No Commands Required)

  • AI Chat & Conversation: Mention or reply to Codunot in servers, or message directly in DMs for AI responses. Remembers up to 60 messages per channel/DM, understands Discord reply chains, automatic fallback to secondary model, slang normalization, and humanized responses
  • Web Retrieval: Explicit URL browse/extraction via /browse is active. Auto web search may be disabled or enabled by product configuration (current default configuration: auto-search disabled).
  • Image Analysis: Send images to get AI-powered descriptions and analysis (vote required)
  • File Reading: Upload PDF, DOCX, or TXT files (max 8MB) for automatic content extraction and summaries (vote required)
  • URL Content Extraction: Share links and Codunot will automatically fetch and summarize webpage content (free)
  • Code Auto-Testing: When code is generated in conversation, it is automatically tested and returns error reports only (no AI fix calls)
  • Image Editing: Attach image + describe edits for AI-powered modifications (vote required)
  • Image Merging: Attach 2+ images and say "merge", "combine", or "blend" to merge them (vote required)

Slash Command Features

  • Mode Commands: /funmode, /seriousmode, /roastmode, /teachmerizz online, /teachmerizz irl, /chessmode (/teachmerizz online is free; /teachmerizz irl requires Premium/Gold/Enterprise)
  • Creative Generation: /generate_image, /generate_video, and /generate_tts for text-to-speech with 300+ voices across 60+ languages (vote required)
  • Music Playback: /play [song/URL] with audio filters (Normal, Bass Boost, Nightcore, Slowed, 8D, Treble, Lo-Fi, Vaporwave), /queue, /volume_up, /volume_down, /autoplay, /lyrics. Supports YouTube, SoundCloud, and Spotify via Lavalink (vote required)
  • Developer Tools: /test_code (error reports only, no AI fix calls), /browse [URL] (all free)
  • Transcription: /transcribe for YouTube/Twitch/X/Kick videos max 30 mins (vote required)
  • Fun Actions: /hug, /kiss, /kick, /slap, /wish_goodmorning, /bet, /meme (all free)
  • Server Config: /configure server, /configure channels (server owner only, free)
  • Bot Profile Customization: /customise_bot_profile (Gold/Enterprise only). Supports server nickname overrides and optional avatar image updates; Discord may apply avatar behavior globally depending on platform handling.
  • Natural Language Moderation: Mention the bot with plain English to perform moderation actions (e.g. "@Codunot timeout @user 10m for spamming")
  • Chess: Full chess engine integration with legal move validation, SAN/UCI support, castling, promotions, en passant, resign detection, and AI hints during games

Free Features (No Vote Required)

The following features are completely free with no vote requirements or usage limits:

  • AI chat and conversation (except paid-tier mode variants such as /teachmerizz irl)
  • Web retrieval via /browse and enabled search integrations
  • URL content extraction and browsing (/browse and automatic)
  • Code testing and validation (/test_code, error reporting only, no AI fix calls)
  • All fun action commands (/hug, /kiss, /kick, /slap, /wish_goodmorning, /bet, /meme)
  • Mode switching commands
  • Music queue viewing (/queue)
  • Server configuration (/configure)

Vote-Required Features

The following premium features require a free vote on Top.gg (unlocks for 12 hours):

  • Image generation (/generate_image)
  • Image editing (attach + describe)
  • Image merging (attach 2+ + say "merge")
  • Image analysis (attach image + ask question)
  • Video generation (/generate_video)
  • Text-to-speech (/generate_tts with 300+ voices across 60+ languages)
  • Music playback (/play with audio filters, YouTube/SoundCloud/Spotify)
  • Video transcription (/transcribe for YouTube/Twitch/X/Kick)
  • File reading (PDF, DOCX, TXT uploads)

Vote unlock duration, feature availability, deployment configuration, and access conditions may be updated as needed. Attempting to bypass vote checks or abuse unlock mechanisms is prohibited and may lead to access termination.
