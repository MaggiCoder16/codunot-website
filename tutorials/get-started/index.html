Getting Started

How to start using Codunot in your Discord server

Last update: April 24, 2026

Step 1: Invite Codunot

Use the invite button from the website and approve bot permissions for your server.

Step 2: Configure chat scope

Run /configure server to allow all channels, or /configure channels for selected channels only.

Step 3: Pick your AI mode

Try /funmode, /seriousmode, or /roastmode. Use /model to pick a model.

Step 4: Test key commands

Try /browse, /image_search, /test_code, and /play to verify setup.
