Server Management

How to launch moderation tools for your Discord

Last update: April 24, 2026

Step 1: Complete setup wizard first

Run /setup-moderation and finish all seven steps: bad words, logging location, mod roles, link policy, anti-spam, anti-raid, and exemptions.

Step 2: Tune anti-spam to your server pace

Set a practical threshold (example: 5 messages in 5 seconds) and pair it with automatic timeout + message cleanup for fast incident control.

Step 3: Enable anti-raid protections

Use join-rate thresholds to auto-lock text channels when suspicious mass joins happen. This prevents damage while staff reviews account quality.

Step 4: Standardize discipline actions

Use /warn for early intervention, /mute for temporary cooling, and /ban//unban for severe cases. Keep consistency with clear reason formats.

Step 5: Train moderators on one process

Document one workflow using /case, /warns, and /clearwarns so all staff actions are understandable, logged, and easy to audit later.
