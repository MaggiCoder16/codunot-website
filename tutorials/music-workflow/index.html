Music Operations

How to run stable music sessions with Codunot

Last update: April 24, 2026

Step 1: Start playback with predictable sources

Use /play with clear search terms or direct URLs so the queue starts with the exact track you expect.

Step 2: Maintain queue hygiene

Use /queue, /remove, and /shuffle to keep upcoming tracks clean during active voice sessions.

Step 3: Apply audio filters intentionally

Use one filter style per session to avoid muddy playback. Reset with /resetfilters before switching from nightcore/slow/lofi to another profile.

Step 4: Save proven lineups

Store frequently used event mixes with /playlistcreate and reopen them from /playlist for instant session starts.
