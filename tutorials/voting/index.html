AI Media Unlocks

How voting unlocks Codunot media features

Last update: April 24, 2026

Step 1: Trigger a vote-gated command

Run a locked media command such as /generate_image or /play and open the vote prompt when it appears.

Step 2: Complete one Top.gg vote

Use the vote button and finish verification once. The unlock is tied to your Discord account, so it follows you across supported servers.

Step 3: Use the full unlocked media set

After voting, use image generation/editing, merge, analysis, video generation, TTS, transcription, and music playback/filter commands.
