How voting unlocks Codunot media features

Last update: April 24, 2026

Step 1: Vote on Top.gg

When a media command is locked, click Vote Now and complete your vote.

Step 2: Run media commands

Unlocked commands include /generate_image, /edit_image, /generate_video, /generate_tts, and more.

Step 3: Track unlock duration

Each vote unlocks media features for 12 hours.

FAQ

Do premium users still vote? Premium increases quotas, but vote requirements may still apply to free-gated media flows unless bypassed.
